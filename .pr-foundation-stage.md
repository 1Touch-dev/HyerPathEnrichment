## API Endpoints

```
POST   /api/documents/upload          Upload CV → job_id
GET    /api/documents/jobs/{job_id}   Poll status
POST   /api/documents/search          Semantic similarity search
GET    /api/documents/{id}/cv-data    Get structured CV data
GET    /api/documents                 List user documents
```

## Pipeline Flow

```
User Upload (PDF/DOCX)
      ↓
[API] Validate file → Store → Enqueue
      ↓
[Worker-Document] Parse → Extract text → Store
      ↓
[Worker-Embedding] Chunk → Generate embeddings → Store in pgvector
      ↓
[API] Vector search returns similar CVs
```

## Database Schema

3 new tables:
- `candidate_documents` - CV metadata + raw text
- `document_jobs` - Processing status tracking
- `document_embeddings` - Vector embeddings (1536 dimensions)
